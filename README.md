# TagFour

Four-bar last-line tag desk for bedroom producers and AI-music finishers.

Suno and loop DAWs reprint the last chorus or fade the file. Session players write four live bars after the money chorus: last line, walk home, kit close, brass out. Then silence.

Live samples (FluidR3 piano, upright, nylon, trumpet, violin, acoustic kit) loaded from the PreEight sample bank. No oscillators.

Yesterday's ship was PreEight (climb into the hook). TagFour is the ending after the last chorus.
